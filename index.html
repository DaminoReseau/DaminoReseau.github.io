Synchronisation Google Sheets

Connexion Google (1 fois)

1
Google Cloud Console Allez sur console.cloud.google.com → créez un projet (ex: "Cordage")
2
Activez Google Sheets API APIs & Services → Bibliothèque → "Google Sheets API" → Activer. Faites pareil pour "Google Drive API".
3
Créez un Client ID OAuth 2.0 APIs & Services → Identifiants → Créer des identifiants → ID client OAuth → Type : Application Web
Origines JS autorisées : ajoutez null (pour fichier local) et votre domaine si hébergé
4
Collez votre Client ID ci-dessous

Vos données restent dans votre Google Drive. Ce fichier ne communique avec aucun serveur externe.
